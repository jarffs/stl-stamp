# 🖌️ SVG Stamp Generator

Este projeto gera carimbos em **3D** a partir de arquivos **SVG**.  
Você pode fazer upload de um SVG, visualizar o modelo em 3D e baixar em **STL** ou **3MF**.

## 🚀 Como usar
1. Vá até a página publicada no GitHub Pages.  
2. Faça upload de um arquivo `.svg`.  
3. Veja a pré-visualização do modelo.  
4. Clique em **Download STL** ou **Download 3MF** para salvar.  

## 💡 Tecnologias
- [Three.js](https://threejs.org/) para renderização 3D  
- STL e 3MF Exporters  

## 🔧 Como rodar localmente
Basta abrir o arquivo `index.html` no navegador.
